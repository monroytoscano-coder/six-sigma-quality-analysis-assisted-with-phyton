# Análisis de Control Estadístico de Procesos (SPC) con Python

Este repositorio contiene la automatización de una auditoría de calidad utilizando principios de la metodología Six Sigma. 

El código desarrollado en **Python (Pandas, Matplotlib)** toma registros industriales simulados (ej. niveles de pH de un reactor), calcula matemáticamente los límites de control superior e inferior ($\pm 3\sigma$) y genera la visualización de la carta de control.

Finalmente, el script aplica filtros lógicos para aislar y reportar automáticamente los lotes exactos que rompen las tolerancias de calidad, eliminando el error de la inspección visual humana.

**Herramientas utilizadas:** Python, Jupyter Notebook, Pandas, Matplotlib, Estadística Industrial.
